# MedMind 💊

A pharmacology study app for PTCB exam prep and pharmacy students, built from firsthand experience as a pharmacy technician.

## Features

- **Flashcards** — flip through the Top 100 drugs with drug name, class, and use
- **Quiz Mode** — multiple choice questions to test recall under pressure
- **Match Mode** — pair drugs to their indications in a timed matching game
- **Weak Cards** — automatically surfaces drugs you've struggled with so you study smarter, not longer

## Why I Built This

I spent years as a pharmacy technician before transitioning into software engineering. MedMind is the study tool I wish I'd had — combining what I knew about pharmacology with what I've learned about building good user experiences.

## Built With

React · TypeScript · Vite · CSS Modules
